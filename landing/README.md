# StatVibe Landing (`statvibe-landing`)

Marketing site + smart device router for StatVibe.

## Vercel

Create project **statvibe-landing** with **Root Directory** = `landing`.

Environment variables:

- `NEXT_PUBLIC_CLIENT_URL=https://stat-vibe.vercel.app/`
- `NEXT_PUBLIC_SERVER_URL=https://statvibe-server.vercel.app`

## Local

```bash
cd landing
cp .env.example .env.local
npm install
npm run dev
```
